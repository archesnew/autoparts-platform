# ZAPTUT.PRO — агрегатор автозапчастей

Стартовый демонстрационный проект на Next.js, TypeScript и App Router. Интерфейс показывает поиск по VIN, OEM или названию и основные категории. Поиск пока демонстрационный: реальные поставщики, заявки и платежи не подключены.

## Запуск

Требуется Node.js 20.9 или новее и npm.

```bash
npm install
npm run dev
```

Откройте http://localhost:3000. Для production-сборки: `npm run build`, затем `npm start`. Проверка стиля: `npm run lint`.

## Структура

- `src/app` — App Router и главная страница.
- `docs/` — описание продукта, архитектуры, модели данных и этапов разработки.

## Перенос на другую платформу

Переносимый исходный архив и порядок подготовки новой среды описаны в [`docs/PLATFORM-MIGRATION.md`](docs/PLATFORM-MIGRATION.md). Архив исходников не содержит секретов, Git-истории или дампа базы данных.

## Примечание

Демо использует только локальные статические данные и не содержит секретов, платных интеграций или production-базы.
