# Архитектура

Публичное имя продукта — **ZAPTUT.PRO** (`https://zaptut.pro`). Визуальные токены интерфейса: графит `#17191B`, оранжевый `#FF6428`, стальные нейтрали и светлые каталожные поверхности.

## Текущий фундамент
Next.js App Router, TypeScript, Tailwind CSS 4, ESLint 9. Главная страница — клиентский компонент только для переключения режима поиска; поиск и каталожные данные пока статичны. Секреты и внешние API отсутствуют.

## Целевая схема
Модульный веб-сервис: Next.js для публичного сайта и кабинетов; PostgreSQL как источник истины; отдельные доменные модули каталога, заявок/CRM, поставщиков, импорта и уведомлений. Начинать как модульный монолит с четкими границами, выносить фоновые задачи и интеграции отдельно при росте нагрузки.

Поток импорта: загрузка → карантин и проверка формата → нормализация → сопоставление товара и автомобиля → публикация версии каталога. Импорт и обновление остатков выполнять идемпотентно через фоновые задания. Хранить источник и время получения каждого предложения.

Поток заявки: валидация → запись заявки → очередь CRM → назначение менеджера → сбор предложений → проверка → ответ покупателю. Аудитировать смену статусов и действий менеджера.

## Нефункциональные требования
RBAC для покупателя, менеджера, администратора и пользователя поставщика; изоляция данных поставщиков; аудит действий; валидация загружаемых файлов; ограничение частоты публичных форм; наблюдаемость и резервное копирование до запуска production. Секреты только в окружении развертывания, никогда в репозитории.

## Интеграции
Сначала CSV/XLSX импорт вручную. Подключать только документированные и разрешенные поставщиком API/фиды. Allegro — отдельное исследование официального API, лицензии, доступов и коммерческих условий; фиктивный адаптер и скрейпинг не входят в фундамент.
