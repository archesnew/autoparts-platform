# Модель данных (проект)

Продукт: **ZAPTUT.PRO** (`https://zaptut.pro`). Ребрендинг не меняет доменную модель.

Это концептуальная схема, не миграция и не подключенная база.

- **User**: идентификатор, email/телефон, хэш учетных данных у провайдера аутентификации, состояние.
- **Organization**: юридическое/торговое имя, страна, контакты, статус проверки.
- **Membership**: user, organization, роль и состояние доступа.
- **Vehicle**: VIN (с ограниченным доступом), марка, модель, поколение, двигатель, год; атрибуты проверки VIN.
- **Product**: канонический товар, название, бренд, категория, характеристики.
- **PartNumber**: номер, тип (OEM/артикул), нормализованное значение, бренд, связь с Product; уникальность по типу и бренду.
- **Fitment**: Product и применимость к автомобилю/варианту, источник и достоверность.
- **SupplierListing**: организация-поставщик, внешний ключ, Product/PartNumber, состояние (новая/б/у), цена и валюта, остаток, срок/условия доставки, URL источника, `observed_at`, срок актуальности.
- **ImportJob**: поставщик, тип и версия файла, состояние, счетчики строк, ошибки, инициатор и временные отметки.
- **Request**: покупатель, контакты, Vehicle, исходный запрос, предпочтения, статус, назначенный менеджер и временные отметки.
- **RequestItem**: Request, искомый номер/описание, количество и параметры состояния.
- **Offer**: RequestItem, SupplierListing или снимок условий, цена/валюта, наличие, доставка, срок, статус и автор проверки.
- **AuditEvent**: субъект, действие, сущность, время и безопасная метаинформация.

Деньги хранить в точной десятичной форме вместе с валютой; состояние товара и предложение фиксировать снимком для истории. VIN и контакты считать персональными/чувствительными данными, задав сроки хранения и доступ по ролям до запуска.
