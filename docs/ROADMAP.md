# Дорожная карта

Проект развивается под брендом **ZAPTUT.PRO** (`https://zaptut.pro`).

## 0. Фундамент (текущий этап)
- [x] Next.js App Router, TypeScript, Tailwind, ESLint.
- [x] Русскоязычная главная и демонстрационные категории.
- [x] Документация домена и целевой модели.
- [ ] Уточнить географию пилота, роли команды и операционный процесс.

## 1. Проверяемый MVP
- Реальная форма заявки с валидацией и защитой от спама.
- PostgreSQL-схема и миграции; локальный/dev контур и тестовые данные.
- CRM: очередь, карточка заявки, статусы, назначение и история действий.
- Кабинет поставщика: профиль, ручной CSV импорт, ошибки строк и предварительный просмотр.
- Каталог нормализованных номеров и предложения с явной актуальностью.

## 2. Пилот
- Роли и изоляция организаций, уведомления, аудит и метрики обработки.
- Сопоставление артикулов и применимости с ручным подтверждением неоднозначностей.
- Импорт по согласованным форматам первых поставщиков; расписание и повторная обработка.
- Проверки доступности, резервирование и политика хранения данных.

## 3. Масштабирование
- Фоновые очереди для объемного импорта, мониторинг качества и SLA.
- Дополнительные страны/валюты, локализация доставки и налоговых правил.
- Исследовать официальные API партнеров, включая Allegro, после правовой и технической проверки.
- Оптимизировать поиск и индексацию по измеренным данным.

Каждый этап уточняется по интервью с покупателями и поставщиками; не обещать наличие или совместимость без источника и времени проверки.
